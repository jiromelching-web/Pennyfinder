What this is: items shoppers have scanned at $0.01 somewhere (from Penny Recon's public list). Penny pricing is set store by store, so a lead is only a hint for your 6 stores. Any $0.01 item that shows up in a store's stock data is pinned at the top as store data. Before you buy, scan the item's own barcode at self-checkout.

Saved only on this phone. Import format: CSV with columns store_id,sku,title,price,was,aisle,note,date (or a JSON array with the same keys). Imported finds show up in the Clearance tab too.

How Refresh works

Refresh pulls the newest data/deals.json. A free GitHub Action rebuilds that file from the public sources every 3 hours. To make the Action run right now, add a GitHub token below. Refresh will then start a run and wait about 1–2 minutes for the new data. When this app runs from serve_local.py on a PC, Refresh pulls live data directly.

Instant refresh (optional)

The token is stored only on this phone. Limit it to this one repo with Actions: Read and write permission only.

Data sources

This app doesn't read homedepot.com directly, because Home Depot blocks automated requests from cloud servers. Store clearance comes from Spotted's public city pages, which Spotted rechecks about once a day. Spotted tracks about 1,000 clearance products, not every yellow tag. Aisle and bay aren't in the free data. Home Depot doesn't officially sell penny items, and a store can refuse the sale.
